## 指摘

### 1. Dependabot alerts（脆弱性の通知）が無効
- 重大度: Low（運用）
- 確信度: 確認済み（API が「Dependabot alerts are disabled」を返す）
- 影響: 更新のプルリクエストは週 1 回作られるが、脆弱性が公表されたときの即時の通知と、脆弱性を修正する更新（security updates）は届かない
- 対策（提案）: リポジトリの Settings → Advanced Security（または Code security）で **Dependabot alerts** と **Dependabot security updates** を有効にする（公開リポジトリは無料）

### 2. Node.js の 22 系は 2027-04-30 にサポートが終わる
- 重大度: Info
- 影響: 開発・CI で使う Node.js（本番は Cloudflare の workerd で、Node.js のバージョンには依存しない）
- 対策（提案）: 2027 年の春までに `.node-version` と CI を新しい LTS に移す。Wrangler・Playwright・vitest の対応を確認してから行う
