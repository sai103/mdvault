## 指摘

### 1. 承認待ち画面のタイマーが、ログイン後にページを再読み込みする
- 重大度: Medium（データの消失）
- 確信度: 確認済み（E2E テストで再現）
- 根拠: 以前の `public/app.js` の `setTimeout(boot, …)`、書き直し中の `client/auth.js` の `checkLogin`
- 影響: 最初の 1 台をブートストラップしてから数秒以内に書いた内容が、自動保存の前の再読み込みで失われる
- 対策: 次の画面に進んだらタイマーを止め、再読み込みせずにアプリを開くようにした。起動処理を 1 回だけにした。テスト: E2E「悪意のある Markdown…」（直前のテストからの続きで発生していた）

### 2. CodeMirror が CSP（`style-src 'self'`）に止められる
- 重大度: Info（CSP を緩めないための設計判断）
- 確信度: 確認済み（ブラウザのコンソールに CSP 違反）
- 根拠: CodeMirror（style-mod）はページへ `<style>` を追加して見た目を付ける
- 影響: `'unsafe-inline'` を許すと、ノートに書いた HTML の `<style>` などでページの見た目を変えられる余地が増える
- 対策: エディタを Shadow DOM の中に置き、CSP の対象外の方法（constructable stylesheet）で見た目を付けるようにした。CSP は変えていない。テスト: E2E 全体で CSP 違反がないこと

### 3. オフライン判定が `navigator.onLine` だけだと、保存できないことに気づけない
- 重大度: Low（データの消失につながりうる）
- 確信度: 確認済み（E2E テストで、つながっていない状態でも `navigator.onLine` が true になる場合があった）
- 対策: 保存がネットワークのエラーで失敗したときにも、オフラインの表示と下書きの保存・10 秒ごとの再送を行うようにした。テスト: E2E「オフラインでも…」

### 4. バックアップが画像の API から読めないようにする
- 重大度: Info（設計時に対応）
- 根拠: バックアップと画像は同じ R2 バケット
- 対策: バックアップは `_mdvault/` の下に置き、画像の API（取得・アップロード）とフォルダ名では `_mdvault/` を扱えないようにした。テスト: 「バックアップは画像の API からは読めず…」「画像は元のパスのまま取り込め…」「アプリ用の名前（_mdvault）…のフォルダは作れない」

### 5. 暗号化前の内容が残る場所
- 重大度: Low（仕様上の限界）
- 確信度: 確認済み（設計上）
- 影響: 暗号化する前に作られた自動バックアップ・書き出した zip・（削除しなかった場合の）履歴には平文が残る。ノート名（パス）は暗号化されない
- 対策: 暗号化するときに履歴を消す選択肢（既定でオン）と、バックアップ・zip に残ることの案内を出す。docs/security.md の残存リスクに記載。テスト: E2E「ノートを暗号化すると…」（サーバーに暗号文だけ・履歴が 0 件）

### 6. 開発用の依存の脆弱性が増えた
- 重大度: Low（本番には含まれない）
- 確信度: 確認済み（`npm audit`）
- 根拠: @cloudflare/vitest-pool-workers 0.23.0（テスト用）が miniflare 経由で sharp・undici・zod を使う
- 対策: 最新版でも未修正のため残存リスクとして記録。Dependabot（今回追加）の更新で再確認する
