# mdvault 使いかたマニュアル

mdvault は、自分専用の Markdown ノートアプリです。ブラウザで開いて使います。
このマニュアルは、**すでに Cloudflare に公開された mdvault を使う人**向けです。公開の手順は [deploy.md](deploy.md)、自分の PC で試す手順は [local-development.md](local-development.md) を参照してください。

> 文中のフォルダ名（`daily`・`templates`・`attachments`）や日数・回数は、初期設定の値です。管理者が `wrangler.jsonc` で変更している場合があります。

## 1. はじめに: ログインのしくみ

mdvault のノートを読み書きするには、次の **2 つの両方**が必要です。

| 必要なもの | 内容 |
| --- | --- |
| **承認済みのデバイス** | 使うブラウザを、あらかじめ「このブラウザは使ってよい」と承認しておく |
| **パスキーでのログイン** | 指紋・顔認証・PIN などで本人確認する。パスワードはありません |

URL を知られても、承認されていないブラウザからはノートを見られません。

- 「デバイス」は**ブラウザ単位**です。同じ PC でも、Chrome と Edge は別のデバイスになります。シークレットウィンドウや、Cookie を消したブラウザも別のデバイス扱いです
- 14 日間使わないと、再ログインが必要です（使っている間は自動で延長されます）。使い続けていても、90 日ごとに再ログインを求められます
- 90 日間使われなかったデバイスは、自動で承認が取り消されます

## 2. 最初の 1 台を使えるようにする

最初の 1 台だけは、公開するときに決めた合言葉（`BOOTSTRAP_SECRET`）で自分を承認します。

1. ブラウザで mdvault の URL を開く
2. 「デバイス名」に分かりやすい名前（例: `自宅PC`）を入れ、**「このデバイスを登録」**を押す
3. 承認待ちの画面になるので、**「最初の1台の場合（ブートストラップ）」**を開く
4. `BOOTSTRAP_SECRET` の値を入力し、**「承認する」**を押す
5. パスキーの登録画面になる。「パスキーの名前」（例: `Windows Hello`）を入れ、**「パスキーを登録」**を押す
6. OS やブラウザの画面が出るので、指紋・顔認証・PIN などで確認する
7. ノートの画面が開けば完了です

> **ブートストラップは、承認済みのデバイスが 1 台もないときだけ使えます。** 2 台目以降は、次の章の方法で承認します。
> 合言葉を 1 時間に 10 回まちがえると、1 時間使えなくなります。

## 3. 2 台目以降のデバイスを追加する

新しいデバイス（例: スマートフォン）を追加するには、**すでにログインしているデバイス**で承認します。

**新しいデバイスで:**

1. mdvault の URL を開き、デバイス名を入れて「このデバイスを登録」を押す
2. **6 桁のコード**が表示される。この画面は開いたままにしておく

**ログイン済みのデバイスで:**

3. サイドバー下の **⚙（デバイスとパスキー）**を開く
4. デバイスの一覧に、新しいデバイスが「承認待ち」で出ている。6 桁のコードを入力して**「承認」**を押す
5. 本人確認（パスキー）を求められたら、指紋などで確認する

**新しいデバイスで:**

6. 数秒で画面が切り替わる。**「パスキーでログイン」**を押してログインする

ログインに使えるパスキーは、次のどれかです。

- iCloud キーチェーンや Google パスワードマネージャーなどで**同期されたパスキー**（同じアカウントの端末なら、そのまま使えます）
- **別の端末のパスキー**: ログインの画面で「別のデバイスを使う」などを選ぶと QR コードが出るので、パスキーを登録したスマートフォンで読み取る
- **USB セキュリティキー**

> 承認待ちのデバイスは、24 時間たつと自動で消えます。その場合はもう一度「このデバイスを登録」からやり直してください。
> 承認されただけのデバイスからは、新しいパスキーを登録できません。新しいパスキーは、ログインした後に ⚙ から追加します（[19 章](#19-デバイスとパスキーの管理)）。

| ボタン | 内容 |
| --- | --- |

### スマートフォンでは

画面が狭いときは、サイドバーは ☰ で引き出すメニューになります。

## 5. ノートを書く

### ノートを作る

- **＋ ノート**（`Alt+N`）を押し、ノート名を入力する。`仕事/議事録` のように `/` で区切ると、フォルダの中に作れる
- クイックスイッチャー（`Ctrl+P`）で、まだないノート名を入力して Enter でも作れる
- 本文の `[[まだないノート]]` をクリックしても作れる

### 保存

- **自動で保存されます。** 入力が止まると、すぐ（1 秒ほどで）保存されます。ツールバーに「保存済み」と出れば完了です
- すぐに保存したいときは `Ctrl+S`（Mac は `Cmd+S`）

### 名前を変える

ツールバーのノート名を書き換えて Enter を押します（Esc で取り消し）。
**他のノートからこのノートへの `[[リンク]]` も、自動で新しい名前に書き換わります。**

### エディタの便利な動き

- カーソルのない行では、`#` や `**`、`[[ ]]` などの記号が隠れて、読みやすく表示されます（[18 章](#18-表示の設定)でオフにできます）
- リストの行で Enter を押すと、次の行も `- ` や `1. ` で始まります
- `[[` と入力するとノート名の候補、`#` と入力するとタグの候補が出ます
- エディタの中のリンクは `Ctrl`（Mac は `Cmd`）+ クリックで開けます
- `Ctrl+F` でノートの中を検索できます

### 他のデバイスで同時に編集したとき

別のデバイスで先に更新されていると、保存のときに確認が出ます。

- **OK**: サーバーの内容（他のデバイスでの変更）を読み込む。ここでの変更は捨てる
- **キャンセル**: ここでの内容で上書きする

どちらを選んでも、上書きされた側の内容は[履歴](#15-履歴ゴミ箱自動バックアップ)から戻せます。

## 6. Markdown の書きかた

よく使う書きかたです。Obsidian とほぼ同じです。

| 書きかた | 表示 |
| --- | --- |
| `# 見出し`、`## 小見出し` | 見出し（`#` の数で大きさが変わる） |
| `**太字**`、`*斜体*`、`~~取り消し~~` | **太字**、*斜体*、~~取り消し~~ |
| `- 項目`、`1. 項目` | 箇条書き、番号付きリスト |
| `- [ ] やること`、`- [x] 済み` | チェックボックス。**プレビューでクリックすると本文の `[ ]` と `[x]` が切り替わる** |
| `> 引用` | 引用 |
| `` `コード` `` | 行内のコード |
| ` ``` `（3 つ）で囲む | コードのかたまり |
| `[文字](https://example.com)` | Web のリンク |
| `\| 列1 \| 列2 \|` と `\| --- \| --- \|` | 表 |
| `---` | 区切り線 |

### frontmatter（ノートの情報）

ノートの**先頭**に `---` で囲んで書くと、プレビューで表として表示されます。

```markdown
---
tags: [仕事, 会議]
date: 2026-10-30
---
```

`tags` に書いたタグは、本文の `#タグ` と同じように扱われます。

> HTML を書くこともできますが、安全のため `<script>` や `onclick` などは取り除かれます。

## 7. リンクと埋め込み

### ノートへのリンク

| 書きかた | 意味 |
| --- | --- |
| `[[ノート名]]` | ノートへのリンク |
| `[[ノート名\|表示する文字]]` | 別の文字で表示するリンク |
| `[[ノート名#見出し]]` | ノートの中の見出しへのリンク |
| `[[フォルダ/ノート名]]` | 同じ名前のノートが複数あるとき |

- `[[` と入力すると候補が出ます
- まだないノートへのリンクは色が変わり、クリックするとそのノートが作られます
- リンクされている側のノートでは、右側の**バックリンク**に表示されます

### 埋め込み

先頭に `!` を付けると、リンク先の内容をその場所に表示します。

| 書きかた | 意味 |
| --- | --- |
| `![[ノート名]]` | ノート全体を埋め込む |
| `![[ノート名#見出し]]` | その見出しの部分だけを埋め込む |
| `![[画像.png]]` | 画像を表示する |
| `![[画像.png\|300]]` | 幅 300 ピクセルで表示する |

## 8. ノートとフォルダの整理

| やりたいこと | 方法 |
| --- | --- |
| フォルダを作る | サイドバーの 📁。フォルダの「⋯」→「この中に新しいフォルダ」 |
| フォルダの中にノートを作る | フォルダの「⋯」→「この中に新しいノート」 |
| 名前の変更・移動 | ノートやフォルダを右クリック（またはフォルダの「⋯」）→「名前の変更・移動」。`/` で区切ると別のフォルダへ移動 |
| ドラッグで移動 | ノートやフォルダを、移動先のフォルダへドラッグ&ドロップ |
| 削除 | 右クリック →「削除」、またはツールバーの 🗑。**ゴミ箱から戻せます** |
| フォルダの削除 | フォルダの「⋯」→「削除」。中のノートはすべてゴミ箱へ移る |

- 名前の変更・移動をすると、**そのノートを指している他のノートの `[[リンク]]` も自動で書き換わります**。書き換わった側の元の内容は履歴に残ります
- 空のフォルダも作れます
- `_mdvault` という名前のフォルダはアプリ用なので使えません
- 一度に扱えるのは 500 件までです（大きなフォルダの名前変更・削除・取り込み）

## 9. タグ

- 本文に `#タグ` と書くとタグになります。`#仕事/会議` のように `/` で階層にできます
- frontmatter の `tags` も同じタグとして扱われます
- `#` と入力すると、使ったことのあるタグの候補が出ます
- プレビューのタグや、サイドバーの「タグ」の一覧をクリックすると、そのタグのノートで絞り込めます

> `#123` のような数字だけのもの、コードの中の `#` はタグになりません。

## 10. 検索とクイックスイッチャー

### 全文検索

サイドバーの検索欄（`Ctrl+Shift+F`）に入力します。

| 書きかた | 意味 |
| --- | --- |
| `議事録 予算` | 両方の語を含むノート（空白で区切ると AND） |
| `"週次 レビュー"` | 語句をそのまま検索 |
| `tag:仕事` | タグで絞り込む（`仕事/会議` などの子のタグも含む） |
| `path:projects` | ノートの場所（フォルダ名など）で絞り込む |
| `設計 tag:work path:projects` | 組み合わせ |

- ノート名に一致するものが上に表示され、一致した箇所が強調されます
- ↑↓ で選び、Enter で開きます。Esc で検索を閉じます

### クイックスイッチャー

`Ctrl+P`（または ⌕）で開き、ノート名の一部を入力して Enter で開きます。一致するノートがなければ、その名前で新しく作ります。

## 11. 今日のノートとテンプレート

### 今日のノート

📅（`Alt+D`）を押すと、`daily/2026-10-30` のような今日の日付のノートを開きます。なければ作ります。
`templates/daily` というノートがあれば、それをひな形にして作ります。

### テンプレート

1. `templates` フォルダにノートを作る（例: `templates/議事録`）。これがテンプレートになる
2. 使いたいノートを開き、ツールバーの 📄 を押してテンプレートを選ぶ
3. カーソルの位置に挿入される

テンプレートの中では、次の書きかたが自動で置き換わります。

| 書きかた | 置き換わる内容 |
| --- | --- |
| `{{title}}` | ノート名 |
| `{{date}}` | 今日の日付（`2026-10-30`） |
| `{{time}}` | 今の時刻（`14:05`） |
| `{{time:HH時mm分}}` | 書式を指定した時刻（`14時05分`） |
| `{{date:YYYY年MM月DD日}}` | 書式を指定した日付（`2026年10月30日`） |

## 12. 画像

### 添付する

次のどれかの方法で、開いているノートに画像を入れられます。

- 画像をコピーして、エディタに**貼り付け**（`Ctrl+V`）
- 画像ファイルをエディタに**ドラッグ&ドロップ**
- ツールバーの 📎 からファイルを選ぶ

画像は `attachments` フォルダに保存され、本文には `![[画像の名前]]` が入ります。

- 使える形式: PNG・JPEG・GIF・WebP・AVIF（1 ファイル 10MB まで）
- 大きい写真は、アップロードの前に自動で縮小されます（長い辺が 2560 ピクセルまで）
- 写真に含まれる**位置情報などの情報（EXIF）は自動で取り除かれます**

### 一覧・削除

サイドバーの 🖼 で、アップロードした画像の一覧を表示します。

- それぞれの画像が、いくつのノートで使われているかが表示されます。「**未使用**」の画像は削除しても困りません
- 「挿入」で開いているノートに入れる、「削除」で削除します（削除した画像は元に戻せません）

## 13. グラフビュー

サイドバーの 🕸 で、ノートのつながり（`[[リンク]]`）を図で表示します。

- 点がノート、線がリンクです。リンクの多いノートほど点が大きくなります
- 点をクリックするとそのノートを開きます。ドラッグで動かす、マウスのホイールで拡大・縮小できます
- 「開いているノートの周りだけ」をオンにすると、今のノートとつながっているノートだけを表示します

## 14. ノートの暗号化

大事なメモは、ノートごとにパスフレーズで暗号化できます。暗号化は**ブラウザの中**で行われ、サーバーには暗号文だけが保存されます。

### 暗号化する

1. ノートを開き、ツールバーの 🔒 を押す
2. パスフレーズ（8 文字以上）を 2 回入力する
3. 「これまでの履歴（暗号化前の内容）を削除する」は、通常はオンのままにする
4. OK を押す

### 暗号化したノートを開く

ノートを開くとパスフレーズの入力欄が出るので、入力して「開く」を押します。
「このタブを開いている間は覚えておく」をオンにすると、タブを閉じるまで再入力が不要になります。

### 暗号化を解除する

ノートを開いた状態で 🔒 を押し、確認で OK を押します。

### 注意

- **パスフレーズを忘れると、誰にも元に戻せません**（管理者にも、このアプリにも）。パスワードマネージャーなどに控えておいてください
- 暗号化したノートは、検索・タグ・バックリンクの対象外になり、グラフビューにもリンクが表示されません。名前を変えても、中のリンクは書き換わりません
- **ノート名は暗号化されません。** 名前に秘密を書かないでください
- 暗号化する**前**に作られた自動バックアップや書き出した zip には、暗号化前の内容が残っています

## 15. 履歴・ゴミ箱・自動バックアップ

### 履歴（🕘）

ノートの過去の版を表示し、元に戻せます。

- 編集中は、10 分おきに 1 つ版が残ります。名前の変更・リンクの書き換え・取り込み・復元の前の内容も残ります
- ノートごとに新しい 50 件まで残ります
- 版を選んで「**この版に戻す**」を押すと戻ります（戻す直前の内容も履歴に残るので、やり直せます）

### ゴミ箱（♻）

削除したノートの一覧です。「復元」を押すと元の場所に戻ります。

### 自動バックアップ（🗄）

毎日 1 回、すべてのノートが自動でバックアップされます（30 日分）。

1. 🗄 を開き、日付を選ぶ
2. その日のノートの一覧から、戻したいノートを選ぶ（「ノートを絞り込み」で探せる）
3. 内容を確認して戻す（現在の内容は履歴に残る）

- 「**今すぐバックアップ**」で、その場でバックアップを作れます。大きな整理をする前などに使ってください
- バックアップに入るのはノートだけです。画像は入りません。画像も残したいときは、[書き出し](#16-obsidian-との取り込み書き出し)を使ってください

## 16. Obsidian との取り込み・書き出し

サイドバーの ⇅ を開きます。

### 書き出し

「**zip で書き出す**」を押すと、すべてのノートと画像を zip でダウンロードします。
展開したフォルダは、Obsidian で Vault としてそのまま開けます。手元に定期的に保存しておくと安心です。
暗号化したノートは、暗号文のまま書き出されます。

### 取り込み

1. Obsidian の Vault のフォルダを zip にする
2. 「zip を選ぶ」でその zip を選ぶ
3. 同じ名前のノートがあるときに上書きするかを選ぶ（上書き前の内容は履歴に残る）
4. 「取り込む」を押す

- `.md` のノートと、画像（PNG・JPEG・GIF・WebP・AVIF）を取り込みます
- `.obsidian` フォルダや隠しファイルは無視します
- 1 回に取り込めるノートは 500 件までです。多いときはフォルダごとに分けてください

## 17. オフラインで使う・ホーム画面に追加する

### ホーム画面に追加

スマートフォンやタブレットでは、ブラウザのメニューの「ホーム画面に追加」で、アプリのように起動できます（PC の Chrome・Edge では「インストール」）。

### オフラインのとき

- 画面の上に「オフラインです」と表示されます
- **一度開いたノートは、オフラインでも読めます**
- オフライン中に書いた内容は、その端末に保存されます。接続が戻ると自動で送られます
- 送る前に、他のデバイスで同じノートが更新されていた場合は、どちらを残すか確認が出ます

> ログアウトすると、端末に残したノートとまだ送っていない内容は消えます。オフライン中の変更が残っているときは、ログアウトの前に確認が出ます。

## 18. 表示の設定

サイドバーの 🎨 で変更します。設定は**その端末だけ**に保存されます。

| 設定 | 内容 |
| --- | --- |
| テーマ | 端末の設定に合わせる / ライト / ダーク |
| 文字の大きさ | 12〜22 |
| エディタの文字 | 通常 / 等幅 |
| 編集中も記号を隠す | オンにすると、カーソルのない行の `#` や `**` を隠す（ライブプレビュー） |

## 19. デバイスとパスキーの管理

サイドバーの ⚙ で開きます。

### デバイス

- 承認済み・承認待ちのデバイスと、最後に使われた日時の一覧です
- **承認**: 承認待ちのデバイスに表示されている 6 桁のコードを入力して承認する（[3 章](#3-2-台目以降のデバイスを追加する)）
- **拒否**: 心当たりのない承認待ちのデバイスは「拒否」で消す
- **削除**: そのデバイスはすぐに使えなくなる。**紛失した端末や、使わなくなったブラウザは削除してください**

### パスキー

- 「**パスキーを追加**」で、今使っているデバイスにパスキーを追加できます（例: PC の Windows Hello に加えて、スマートフォンにも登録しておく）
- 削除すると、そのパスキーでログインしていた状態はすべて解除されます
- **最後の 1 つのパスキーは削除できません**

> パスキーを 1 つしか持っていないと、その端末を失ったときにログインできなくなります。**2 つ以上（別の端末やセキュリティキー）登録しておくことをおすすめします。**

### 本人確認

デバイスの承認・削除、パスキーの追加・削除のときは、もう一度パスキーでの本人確認を求められます（直前 5 分以内に確認していれば不要）。

### ログアウト

「ログアウト」を押すと、この端末でのログインを終了します。端末に残したノートの控えも消えます。
デバイスの承認は残るので、次はパスキーでログインするだけで使えます。

## 20. ショートカット一覧

Mac では `Ctrl` の代わりに `Cmd` を使います。

| キー | 内容 |
| --- | --- |
| `Ctrl+P` | クイックスイッチャー（ノートを開く・作る） |
| `Ctrl+S` | すぐに保存 |
| `Ctrl+E` | 編集と閲覧の切替 |
| `Ctrl+Shift+F` | 全文検索 |
| `Ctrl+F` | ノートの中を検索（エディタ） |
| `Alt+N` | 新しいノート |
| `Alt+D` | 今日のノート |
| `Ctrl` + クリック | エディタの中のリンクを開く |
| `Esc` | メニュー・検索を閉じる。ノート名の編集を取り消す |

## 21. 困ったとき

| 症状 | 対処 |
| --- | --- |
| 「このデバイスはまだ登録されていません」と出る | 初めてのブラウザか、Cookie が消えた。[3 章](#3-2-台目以降のデバイスを追加する)の手順で承認する |
| 承認待ちのまま進まない | ログイン済みのデバイスの ⚙ で、表示されている 6 桁のコードを入力して承認する。24 時間たったら登録からやり直す |
| ブートストラップで「承認済みのデバイスがあるため使えません」 | すでに 1 台承認されている。そのデバイスから承認する。承認済みのデバイスが手元にないときは管理者に相談する（[cloudflare.md](cloudflare.md#デバイスやパスキーをすべて失ったとき)） |
| パスキーの画面が出ない・失敗する | ブラウザを最新にする。パスキーを保存できない環境（Linux の PC など）では、スマートフォン（QR コード）やセキュリティキーを使う |
| 「パスキーは HTTPS か localhost でしか使えません」 | `https://` の正しい URL で開き直す |
| 急にログイン画面に戻った | 14 日間使わなかったか、ログインから 90 日たった。パスキーでログインし直す |
| 「本人確認」を何度も求められる | デバイスやパスキーの操作は、安全のため 5 分ごとに確認を求める。そのまま確認する |
| 「保存済み」にならない・「オフライン」と出る | 通信できていない。内容は端末に残っているので、つながると自動で送られる |
| 「他のデバイスで更新されています」と出る | [5 章](#5-ノートを書く)の「他のデバイスで同時に編集したとき」を参照 |
| 消してしまった | ♻ ゴミ箱から復元する。書き換えてしまった場合は 🕘 履歴、それでもなければ 🗄 自動バックアップから戻す |
| 暗号化したノートのパスフレーズを忘れた | 戻せません。暗号化する前の自動バックアップや書き出した zip が残っていれば、そこから戻せる |
| 画像を貼り付けられない | 先にノートを開く。形式（PNG・JPEG・GIF・WebP・AVIF）と大きさ（10MB まで）を確認する |
| 画面が古いまま・表示がおかしい | ページを再読み込みする（`Ctrl+Shift+R`） |
| 端末を紛失した | 別のログイン済みのデバイスで ⚙ を開き、紛失した端末を**削除**する。その端末だけにあったパスキーも削除する |
